🚀 Task Manager API

A RESTful API built with Node.js and Express.js 🟢⚡ that allows users to create, manage, and organize tasks efficiently ✅📋.
It supports user authentication 🔐 with JWT, enabling each user to securely register, log in, and manage their own tasks.
The API provides full CRUD operations (Create ➕, Read 👀, Update ✏️, Delete ❌) with filtering, sorting 🔎, and pagination 📄.
Data is stored in MongoDB 🍃 using Mongoose for schema modeling.

🌟 Key Features

👤 User signup/login with JWT authentication

➕ Create, ✏️ Update, ❌ Delete, and 👀 Fetch tasks

🔎 Filter tasks by completion status

🗂️ Sorting & pagination for easy task management

🔑 Secure password hashing with bcrypt.js

⚙️ Environment variable support with dotenv

🛠️ Tech Stack

🟢 Node.js, ⚡ Express.js

🍃 MongoDB, 📦 Mongoose

🔐 JWT for authentication

🧂 bcrypt.js for password encryption
